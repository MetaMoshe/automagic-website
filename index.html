How we work

Five phases, each ending in a decision

Each phase has a clear output. You can stop after any of them and keep everything produced so far.

  1. PHASE 01

    Discover

    3–4 days

    Interviews, workflow mapping and a data audit. Output: an AI Transformation Report and a prioritised roadmap.

  2. PHASE 02

    Design

    1–2 weeks

    Solution, scope, wave plan, business case and KPIs. Output: a proposal with a fixed price per item.

  3. PHASE 03

    Build in waves

    Set in Design

    Short waves, so your team uses real tools early. Each wave ends in a review and a go or no-go.

  4. PHASE 04

    Adopt

    Alongside every wave

    Hands-on training, office hours and champions in each team, so the tools get used.

  5. PHASE 05

    Run and evolve

    Ongoing

    Monitoring, tuning, cost control and ROI reviews that shape the next stage.

We don't decide what to build before discovery. What gets built, and how long it takes, comes from what we find.
